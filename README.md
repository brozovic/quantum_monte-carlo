# quantum_monte-carlo

Exploratory Quantum Monte Carlo (QMC) Simulations

This repository contains the source code and computational pipeline for exploratory Quantum Monte Carlo (QMC) simulations integrated with noisy intermediate-scale quantum (NISQ) algorithms. The project investigates the convergence behaviors, error scaling, and resource requirements of quantum amplitude estimation methods when applied to stochastic multi-dimensional integration and state preparation.
By leveraging a combination of classical Monte Carlo verification and quantum circuit simulations, this exploratory framework benchmarks the practical trade-offs between sample size, circuit depth, and target precision (ε).
